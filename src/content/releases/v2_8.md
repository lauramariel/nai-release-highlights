---
version: "2.8"
release_date: 2026-08-20
summary: "Nutanix Enterprise AI 2.8 introduces fine-grained authorization, model sharing through authorization policies, fine-tuning GA, MCP GA, enhanced vLLM parameter management, and expanded support for NVIDIA NIMs in air-gapped environments. This release also adds multi-node inferencing, KV cache offloading, and new Hugging Face LLM models as tech preview or generally available capabilities."
features:
  - title: "Fine-Grained Authorization and Owner-Scoped Access"
    description: "Administrators can now control access to individual UI actions and resources through IAM-mapped permissions. Supports pre-defined system roles and custom roles, authorization policies scoped to specific NAI entities, and owner-scoped access so users can manage only the resources they created."
    category: "Security"
  - title: "Model Sharing Through Authorization Policies"
    description: "Enables sharing of imported models with specific users or user groups via authorization policies. Authorized users can view shared models on the Models page and select them when creating endpoints, providing granular model-level access control."
    category: "Security"
  - title: "Licensing Support for Agent Gateway Capabilities"
    description: "NAI now supports an Agent Gateway license in addition to CPU and GPU licenses, providing access to unified endpoints and Model Context Protocol (MCP) servers. The license can be added and managed from the Licensing tab alongside existing NAI licenses."
    category: "Platform"
  - title: "Ability to View and Download MCP Server Logs"
    description: "Enhanced log management for MCP servers allows users to view and refresh logs for an MCP server instance directly from the NAI console, and download up to 10 MB of log lines to their local system for troubleshooting and analysis."
    category: "MLOps"
  - title: "Messages API Support in Agent Gateway"
    description: "Unified endpoints now include support for the messages API specification for Anthropic provider APIs."
    category: "API"
  - title: "Document Grounding and Citations in the Agent Application"
    description: "NAI supports document grounding in Agent, enabling users to provide documents as a trusted knowledge source. Grounded responses include source citations with links to the source document, specific text chunks used, and surrounding content. Configurable via embedding and reranker endpoints in NAI Labs."
    category: "Core"
  - title: "Unified Endpoint Rate Limit Enhancements"
    description: "Unified endpoint rate limiting now includes per-client controls with Identify Clients By options for API Client Key or Request Header Value, Measured Unit and Frequency fields, default rate limits per header value, and optional overrides for specific header values."
    category: "Platform"
  - title: "Fine-Tuning GA and Enhanced Capabilities"
    description: "Fine-tuning is now generally available. Enhancements include configurable training parameters (folder name, file server, NFS path, sequence length, batch size, gradient accumulation, vCPUs, memory), training progress monitoring with Step Loss/Learning Rate/Grad Normalization metrics retained for six months, import of completed fine-tuned models, and the ability to pause and resume jobs from the last saved checkpoint."
    category: "MLOps"
  - title: "Support for NVIDIA NIMs in Air-Gapped Environments"
    description: "NVIDIA NIMs can now be manually imported into air-gapped environments from an NFS file share or S3-compatible object bucket without requiring access to the NVIDIA NGC Catalog or an external container registry. Users must specify model capabilities, storage requirements, developer, and source location during import."
    category: "Platform"
  - title: "Support for Non-Catalog NVIDIA NIMs"
    description: "NAI now allows importing NIMs beyond pre-validated options by providing the NIM container image path from the NVIDIA NGC Catalog. Only images hosted in the nvcr.io/nim registry are supported. Endpoints can be created once the imported NIM reaches the Ready state."
    category: "Platform"
  - title: "Enhanced Management of vLLM Parameters"
    description: "Users can enter and validate custom vLLM arguments and environment variables during endpoint creation, view parsed parameters in the Summary tab before creation, and modify custom arguments and environment variables for experimental endpoints in the Hibernated state via the Manage Parameters action."
    category: "MLOps"
  - title: "MCP GA and Server Enhancements"
    description: "MCP is now generally available. Updates include managing MCP key-to-connector associations from the MCP Client Keys page, scaling local MCP servers to single-instance deployments, and support for enabling Request Header Forwarding to MCP servers with required header validation for tool requests."
    category: "Platform"
  - title: "Multi-Node Allocation for Local Endpoints"
    description: "Tech preview feature enabling deployment of models using the vLLM Engine across multiple GPU nodes by configuring nodes per endpoint instance and accelerators per node. Available for supported model capabilities with vLLM and GPU Passthrough acceleration; incompatible with speculative decoding and KV cache offloading."
    category: "Performance"
  - title: "KV Cache Offloading for Local Endpoints"
    description: "Tech preview feature for local endpoints using the vLLM inference engine with GPU Passthrough acceleration. Allows configuring the amount of CPU memory allocated for storing the KV cache per accelerator. Not supported for multi-node allocations."
    category: "Performance"
  - title: "Support for New Models"
    description: "Four new Hugging Face LLMs are now pre-validated: mistralai/Mistral-Small-4-119B-2603, mistralai/Mistral-Large-3-675B-Instruct-2512, nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-BF16, and nvidia/NVIDIA-Nemotron-3-Ultra-550B-A55B-BF16."
    category: "Core"
---
